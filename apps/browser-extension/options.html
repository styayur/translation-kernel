Languages & display
Translation providers

Add Google (no key), an OpenAI-compatible endpoint, or Ollama. Content is sent only when you start translation.

Keys stay in local extension storage. They are not encrypted. Only provider origins receive network access when you save.

Site rules

Each rule has match patterns and optional root, include, exclude selectors.

Custom URL actions

Use {text} in the URL. Fields: id, name, urlTemplate, openMode (tab or window). Actions appear in the popup and use selected text.

Change keyboard shortcuts at chrome://extensions/shortcuts. Export omits API keys and custom headers.
