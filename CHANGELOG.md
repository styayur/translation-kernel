# Changelog

## 0.1.0 — 2026-10-08

- Introduced the TypeScript translation microkernel and version 1 public contracts.
- Added HTML semantic discovery, incremental mutation handling and reversible pure-text rendering.
- Added bounded caching, batch scheduling, cancellation, timeout, retry and fallback.
- Added Google convenience, OpenAI-compatible and Ollama-compatible provider examples.
- Added minimal Chromium MV3 popup/settings, keyboard commands and portable config.
- Added isolated typed events, safe URL actions, memory adapter and external bridge projections.
- Added deterministic unit, DOM and real-extension E2E tests, CI, dependency updates and benchmarks.
- Defined MPL library and GPL application boundaries under the studio license policy.
